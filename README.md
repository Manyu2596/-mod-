# 潜渊症 Mod 管理器

给《潜渊症》(Barotrauma) 做的 **Mod 加载顺序管理工具**：拖拽排序、按需启用、一键写入游戏配置、启动前自动体检。

不用在游戏里一个个手动拖动，也不用猜该放前面还是后面。

---

## 主要功能

| 功能 | 说明 |
| --- | --- |
| **可视化拖拽排序** | 左栏是已启用（从上到下加载，越靠下优先级越高），直接拖 |
| **一键启用 / 停用** | 右侧按钮切换，改完点「保存到游戏」即写入 `config_player.xml`（自动备份） |
| **重新排序** | 按规则自动排好：前置框架最前 → 原版微调 → 功能/QoL → 大型内容 → 补丁紧跟本体 → 汉化最底 |
| **启动游戏 + 体检** | 保存配置后拉起游戏，并给出诊断报告：框架冲突、同系列重复、依赖缺失、版本不匹配、可能冲突（重复定义） |
| **中文名与简介** | 内置 50+ 个常用 mod 的中文名与用途说明；新 mod 会自动根据内容生成简介 |
| **路径自动探测** | 从 Steam 注册表与库配置自动找游戏目录和创意工坊目录；找不到可手动指定 |
| **检查更新** | 对比版本快照，提示哪些 mod 被作者更新了、哪些是新订阅的 |
| **独立窗口** | App 模式窗口（无地址栏/无标签页），任务栏独立图标，无黑窗口 |

## 使用方法

### 方式一：绿色版（推荐，免安装）

1. 到 **Releases** 下载 `潜渊症Mod管理器-绿色版.zip`
2. 解压到任意位置
3. 双击 **`潜渊症Mod管理器.vbs`** → 弹出程序窗口（完全没有安装过程，也没黑窗口）

> 想看日志/排查路径问题：双击 `启动.bat`（会保留命令行窗口并显示探测到的路径）。

### 方式二：从源码运行

需要本机装有 Node.js 18+：

```bash
node server.js          # 默认端口 9182，就绪后自动打开浏览器
```

可用环境变量覆盖（端口/路径）：

```bash
BARO_PORT=9191
BARO_GAME="D:\Steam\steamapps\common\Barotrauma"
BARO_WORKSHOP="D:\Steam\steamapps\workshop\content\602960"
BARO_INSTALLED="%LOCALAPPDATA%\Daedalic Entertainment GmbH\Barotrauma\WorkshopMods\Installed"
```

生成绿色版（自带 Node 运行时）：

```powershell
powershell -ExecutionPolicy Bypass -File 打包.ps1
# 产物在 dist\潜渊症Mod管理器\
```

## 排序规则

后加载的覆盖先加载的，所以顺序是：

1. 前置框架（LuaCsForBarotrauma 等）
2. 性能优化
3. 原版机制微调
4. 功能 / QoL
5. 大型内容（角色、物品、潜艇、玩法）
6. 补丁 / 附加包（紧跟它对应的本体，才能正确覆盖）
7. 汉化（放最后，才能盖住英文文本）

## 常见问题

**Q：游戏里 mod 突然全部被禁用了？**
游戏崩溃后，潜渊症自带保护机制会在下次启动时禁用全部 mod。处理：把游戏目录下的 `crashreport*.log` 删掉/移走，再用本工具「保存到游戏」写回，然后重启游戏。

**Q：保存后游戏没反应？**
游戏只在启动时读取配置。改完必须**完全退出游戏再重开**；C# 类 mod 尤其如此（只在启动时编译加载）。

**Q：找不到 mod / 路径不对？**
点「路径设置」→ 先「重新检测」，不行就手动填游戏目录与创意工坊目录（会存到 `paths.json`，优先级最高）。

**Q：翻译按钮没反应？**
「翻译名称」需要本地 Ollama（默认模型 `qwen25-14b-8k`）。没装也不影响使用——内置中文表已覆盖常用 mod；新 mod 可用每行右侧的「译」按钮手动补。

## 隐私说明

- 本工具**只在本机运行**（服务只监听 `127.0.0.1`），不会上传任何数据。
- `zh.json` 里记录了 mod 的中文名与简介，会体现**你订阅了哪些 mod**。若不希望公开，删除该文件即可（功能不受影响，只是没有中文名）。
- `user_zh.json` / `translations.json` / `versions.json` 属个人使用数据，已在 `.gitignore` 中排除。

## 目录结构

```
server.js          # 本地服务 + 全部接口
ui.html            # 界面（拖拽、排序、诊断报告、路径设置）
sort.js            # mod 解析、分类、排序规则、路径探测
zh.json            # 内置中文名与简介
analyze_purpose.js # 根据 mod 内容自动生成用途说明
fetch_meta.js      # 可选：从 Steam 拉取官方标题/简介（需联网）
make_icon.ps1      # 生成应用图标（游戏图标 + 齿轮）
打包.ps1           # 生成自带 Node 运行时的绿色版
```
