# 潜渊症 Mod 管理器

给《潜渊症》(Barotrauma) 管 Mod 的小工具：**看着清楚、拖着排序、点一下就写进游戏**。

不用在游戏里一个个手动拖，也不用猜哪个该放前面。

---

## 它能做什么

- **拖着排序**：左栏就是加载顺序（越靠下越优先），直接拖
- **一键启用 / 停用**：改完点「保存到游戏」，自动备份原配置
- **自动排序**：不确定顺序就点「重新排序」，按规则排好（框架最前、补丁跟本体、汉化最后）
- **启动前体检**：框架冲突、重复启用、缺依赖、版本不匹配，启动游戏前先告诉你
- **导出 / 导入 Mod**：把现在启用的 mod 打成 **一个 zip** 发给朋友，他点「导入zip包」选中就能还原成和你一样的配置（不用解压、不用填路径）
- **一键订阅**：点「订阅链接」生成可发到群里的 Steam 订阅链接（`steam://subscribe/...`），对方点一条就弹订阅确认；导出包里也带 `subscribe.html`；导入时缺哪些 mod，会提示一键订阅补齐
- **Mod 方案存档**：一个游戏存档一套 mod——把当前启用的一套存成方案，换一批再存一个，点「应用」整切换回去
- **中文名**：常用 mod 自带中文名和用途说明

## 使用方法

### 方式一：绿色版（推荐，免安装）

1. 到 **Releases** 下载 `BarotraumaModManager-v1.23.zip`
2. 解压到任意位置
3. 双击 **`潜渊症Mod管理器.vbs`** → 弹出程序窗口（完全没有安装过程，也没黑窗口）

> 想看日志/排查路径问题：双击 `启动.bat`（会保留命令行窗口并显示探测到的路径）。

### 方式二：安装版（自动建快捷方式）

1. 到 **Releases** 下载 `BarotraumaModManager-v1.23-Setup.exe`
2. 双击运行 → 自动安装到 `%LOCALAPPDATA%\潜渊症Mod管理器`，并在桌面与开始菜单生成快捷方式
3. 装完直接双击快捷方式即可

> 安装包未做数字签名，Windows SmartScreen 可能提示「未知发布者」，点「更多信息 → 仍要运行」。
> 不想安装就删掉 `%LOCALAPPDATA%\潜渊症Mod管理器` 文件夹和快捷方式，没有注册表残留。

### 方式三：从源码运行

需要本机装有 Node.js 18+：

```bash
node server.js          # 默认端口 9182，就绪后自动打开浏览器
```

可用环境变量覆盖（端口/路径）：

```bash
BARO_PORT=9191
BARO_GAME="D:\Steam\steamapps\common\Barotrauma"
BARO_WORKSHOP="D:\Steam\steamapps\workshop\content\602960"
BARO_INSTALLED="%LOCALAPPDATA%\Daedalic Entertainment GmbH\Barotrauma\WorkshopMods\Installed"
```

生成绿色版（自带 Node 运行时）：

```powershell
powershell -ExecutionPolicy Bypass -File 打包.ps1
# 产物在 dist\潜渊症Mod管理器\
```

### 把我的 mod 发给朋友

1. 点「导出mod文件」：已启用的 mod 会按加载顺序复制到软件目录下的 exported_mods（内含 manifest.json 记录顺序）
2. **自动打包成一个 zip**（形如 `BarotraumaMods-23mods-20261004-0405.zip`），并打开文件夹帮你选中它，直接把这一个文件发给对方
3. 对方点「导入zip包」选中这个 zip → 自动解压、复制回创意工坊、按原顺序启用并写入游戏配置

> 每次导出会清掉上次残留的旧 mod，只留本次启用的；旧的 zip 也只保留最新一个。
> 导入只认纯数字的工坊 ID 目录，别的 manifest 内容会被忽略，避免来路不明的包写到别的地方。

### 让朋友直接订阅（不用拷文件）

工坊 mod 其实不用拷文件，让对方**订阅**更好（体积小、作者更新时自动同步）。两种方式：

**① 发订阅链接（推荐）**

点工具栏 **「订阅链接」** → 面板里给出当前这套里所有工坊 mod 的链接，切三种形式：

- **Steam 链接**：`steam://subscribe/工坊ID`，复制后发到群里，对方点一条就在 Steam 里弹订阅确认
- **网页链接**：`https://steamcommunity.com/sharedfiles/filedetails/?id=...`，没装 Steam / 手机上也能打开
- **带 mod 名**：每行「中文名 + 链接」，对方一眼知道订阅的是什么

面板里还有「自己先订阅一遍」（本机拉起 Steam 逐个确认）和「打开订阅清单页面」。

**② 发订阅清单页面**

导出包里还有一个 `subscribe.html`：朋友双击打开就是订阅清单，每条都有「Steam 订阅」按钮，
也可以点页面上的「一键订阅全部」。在本工具里导入后，对缺失的 mod 也能点「用 Steam 订阅」。

> Steam 的协议一次只弹一个订阅确认。想让对方**一次订阅全部**，用面板里的
> **「做 Steam 合集」**：在 Steam 里新建合集、把这些 mod 加进去，分享合集链接，对方点「订阅全部」即可。

### 一个游戏存档一套 mod（方案存档）

点工具栏 **「mod方案存档」**：

1. 排好当前这一套启用顺序 → 填个名字（如 `单人战役`）→ 点「保存当前启用」
2. 换一批 mod → 再存一个（如 `联机车队`）
3. 以后点方案右边的「应用」：整份启用列表切换回去并写入游戏配置（会覆盖当前排序）

方案存在软件目录的 `presets` 文件夹里，一个方案一个 JSON 文件，可以自己备份和分享。

## 排序规则

后加载的覆盖先加载的，所以顺序是：

1. 前置框架（LuaCsForBarotrauma 等）
2. 性能优化
3. 原版机制微调
4. 功能 / QoL
5. 大型内容（角色、物品、潜艇、玩法）
6. 补丁 / 附加包（紧跟它对应的本体，才能正确覆盖）
7. 汉化（放最后，才能盖住英文文本）

## 常见问题

**Q：游戏里 mod 突然全部被禁用了？**
游戏崩溃后，潜渊症自带保护机制会在下次启动时禁用全部 mod。处理：把游戏目录下的 `crashreport*.log` 删掉/移走，再用本工具「保存到游戏」写回，然后重启游戏。

**Q：保存后游戏没反应？**
游戏只在启动时读取配置。改完必须**完全退出游戏再重开**；C# 类 mod 尤其如此（只在启动时编译加载）。

**Q：不是 Steam 版（没有创意工坊）能用吗？**
能，但只有「本地 mod」这条路：路径设置里填好**游戏目录**，再把 mod 文件夹（内含 `filelist.xml`）放进**本地 mod 目录**（默认游戏目录下的 `LocalMods`），点「扫描路径」就能看到并正常排序/启用。注意：一键订阅、创意工坊链接这些依赖 Steam，非 Steam 版用不了。

**Q：找不到 mod / 路径不对？**
点「路径设置」→ 先「重新检测」，不行就手动填游戏目录与创意工坊目录（会存到 `paths.json`，优先级最高）。

**Q：翻译按钮没反应？**
「翻译名称」需要本地 Ollama（默认模型 `qwen25-14b-8k`）。没装也不影响使用——内置中文表已覆盖常用 mod；新 mod 可用每行右侧的「译」按钮手动补。

## 隐私说明

- 本工具**只在本机运行**（服务只监听 `127.0.0.1`），不会上传任何数据。
- `zh.json` 里记录了 mod 的中文名与简介，会体现**你订阅了哪些 mod**。若不希望公开，删除该文件即可（功能不受影响，只是没有中文名）。
- `user_zh.json` / `translations.json` / `versions.json` 属个人使用数据，已在 `.gitignore` 中排除。

## 目录结构

```
server.js          # 本地服务 + 全部接口
ui.html            # 界面（拖拽、排序、诊断报告、路径设置）
sort.js            # mod 解析、分类、排序规则、路径探测
zh.json            # 内置中文名与简介
analyze_purpose.js # 根据 mod 内容自动生成用途说明
fetch_meta.js      # 可选：从 Steam 拉取官方标题/简介（需联网）
make_icon.ps1      # 生成应用图标（游戏图标 + 齿轮）
openFolder.ps1     # 打开导出文件夹并把窗口放到屏幕最前
打包.ps1           # 生成自带 Node 运行时的绿色版
```
